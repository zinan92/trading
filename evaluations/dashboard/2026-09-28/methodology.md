# Dashboard 首轮评分方法

首轮、角色相对评分；不代表收益、生产认证或对付费行情/真实账户的授权验收。权重与 Trading Strategy、Trading Infra 使用同一五维方法：

- **核心结果实测：35 分**：产品按建议角色是否交付了可复验的核心结果；认证、依赖、数据源受阻时按未验证计算。
- **数据可信度与时效：25 分**：来源标记、freshness、会话日期、fixture/synthetic 标签和复现状态。
- **覆盖与深度：15 分**：仅计建议角色内实际看到或运行的能力，不因目录中有 pane/API 名称直接给满分。
- **上手与复现：15 分**：安装、离线/无 key 入口、步骤和依赖清晰度。
- **运行稳定性：10 分**：本轮实跑结果、项目测试、依赖和错误状态。

Dashboard 类里有完整网页、TUI、一个 API SDK 和一个图表组件。跨角色总分不能替代适配度；本页只把四个适合 Dashboard 的界面排在同一张榜里。误分类的库/组件另列并打角色分，不把它们当作独立 dashboard 名次。

证据标签：公开无认证实测；隔离本地 fixture；从此前已完成类别复用的截图/结果；因缺 key、账户或服务而未验证。截图数只表示覆盖面，不是功能通过率。
