## 实际操作

- README 将公开版定位为缠论基础元素计算：合并 K 线、笔、线段、中枢、买卖点，以及多级别和绘图；README 也明确排除通用策略和交易引擎。
- 本地使用仓库自带 `DataAPI/csvAPI.py`，生成 320 根明确标注为**合成**的日线 OHLC，调用实际 `CChan` 计算入口。没有请求 Baostock/AkShare/Futu 等行情源。
- 批处理与逐根 `trigger_step` 模式都成功：均得到 320 根原始 K 线、276 根包含处理后的 K 线、25 笔、7 段、2 个中枢、14 个买卖点；增量模式产出 320 次更新，最终元素计数一致。`PlotDriver` 随后生成图表。**这验证结构计算和绘图管道，不验证任何交易收益或实盘信号。**
- 在当前 Python 3.13 环境中，内置库可直接导入和运行；README 仍把 Python 3.11+ 列为最低版本。依赖清单位于 `Script/requirements.txt`，根目录没有 `pyproject.toml`/锁文件。

## 公开版与 README 一致性

README 写明公开版暂不包含策略、模型和交易引擎，但当前仓库确实有 `CustomBuySellPoint`、`ChanModel/Features.py` 和 `Debug/strategy_demo.py` 等基础类/演示。**实际源码范围宽于 README 的概括**，但仍没有一个完整、可直接交易的通用引擎；代码也明确提示 README 某些完整版说明与公开版会不一致。

## 判断与建议定位

建议放在 **Trading Strategy / Chan 形态与技术结构计算引擎**：适合已经掌握缠论定义、希望把结构元素转成可读对象并自行接策略的 Python 开发者。它不是面向普通交易者的应用，也不提供可直接用来排名盈利能力的成品策略。增量/批处理一致性在本次合成样本上通过；其他边界、真实市场数据准确性和买卖点经济有效性仍未验证。

本轮没有交易账户、没有交易 API 调用或订单；合成图中的 B/S 标签不是买入建议。
