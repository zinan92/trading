# Trading Strategy 评分方法

本轮是首轮实测，不是收益评级、生产认证或完整交易系统覆盖评分。五项按 Data 与 Equity Research 类一致口径计分：

- **核心结果实测：35 分**，产品自述的主要任务是否得到真实、可复验结果；密钥缺失或产品阻断按未验证计，不把空数据当成功。
- **数据可信度与时效：25 分**，输入的来源、时效、合成/实盘区分、计算可复现性与结果边界。纯指标/策略库按其输入契约和离线重现情况评估，不因为它本身不采行情而假定已有可信数据。
- **覆盖与深度：15 分**，针对产品建议角色的能力范围与实现深度，不拿库是否有 Dashboard 与完整系统横向比。
- **上手与复现：15 分**，安装、配置、清洁环境、样例和运行步骤是否可达。
- **运行稳定性：10 分**，本轮运行与项目测试、错误态和可复现性。

分数用于本类首轮优先级比较；功能定位不同，几分差距不能替代角色判断。截图数量是证据留存量，不等于相同数量功能通过。Native UI 与辅助评测页分开标注。所有含收益数字的回测样例均使用合成数据，不代表真实行情或收益。
