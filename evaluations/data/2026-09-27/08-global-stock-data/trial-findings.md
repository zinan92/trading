- 原仓库：https://github.com/simonlin1212/global-stock-data
- 实际试用源码 `5f27525709ab043b91e53d7a420ce6d46e66a0ce`，Skill 版本 `2.0.3`；Trading 目录锁为较早的 `fbf0ae47d64e24fdfce5fbc724b3041adc510739`。
- 项目是 `SKILL.md` 中嵌入的 Python 取数与计算代码，没有原生 Web 页面或常驻 API Server。本轮在隔离 Python 3.12 环境只安装 `requests`，执行已人工检查的代码块。[机器记录](evidence/probes.json)、[辅助证据页](evidence/index.html)与[截图](screenshots.md)都明确区分官方源、FINRA 单文件摘要、合成指标输入和仅源码声明。

## 实际有结果

1. 美国财政部 2026 年收益率曲线返回 **185 个日期**，最新样本 `2026-09-25`，2 年期 `4.81%`、10 年期 `5.17%`；本地算得 10Y−2Y **+0.36 个百分点**。这是请求当时官方 CSV 的快照，不应被复用为当前市场数据。
2. CFTC 公共报告接口返回最近 20 条记录，最新报告日 `2026-09-22`；按 `E-MINI S&P 500` 过滤又返回 5 条。未经独立核对每个合约持仓字段。
3. FINRA 对 `2026-09-25` 已公开的 **单个** Reg SHO 文件解析出 **12,349** 个符号，并确认 AAPL 存在。只公开文件日期、行数和存在性，不在公开页面再分发原始空头成交量或比例。空头成交量与未平仓空头不是同一个指标。
4. Skill 内嵌的 MA/EMA、MACD、RSI、KDJ、布林带函数都在明确标注的 30 根**合成** K 线上返回结构化结果；这是算法路径烟测，不代表市场数据源或策略收益经过验证。
5. 对 SEC 缺少真实联系人 UA 的调用在网络请求前明确抛错；港股代码传入仅美股层也被拒绝。这两个是预期输入守卫。

## 限制与具体发现

- SEC EDGAR 的远端申报/基本面层没有调用：本轮没有可声明给 SEC 的真实联系人名称与邮件。CBOE 期权全链/Greeks、Nasdaq 财报日历以及 Yahoo/新浪/腾讯/东财行情也没有在这轮对外可公开取数范围内验证。README 和 Skill 中存在函数不等于其当前返回成功。
- FINRA 属于作者标注的受限源；本轮只下载一个已发布日文件用于私人验证。发布评测时不放原始记录。
- `calc_rsi` 对 **完全平盘**的 30 根合成 K 线返回 `rsi6=rsi12=rsi24=100`。在无涨无跌时这会呈现“极度超买”，建议在使用前处理零收益/零损失的边界。其余指标仅做基本执行烟测，未对数学口径全面基准测试。
- 仓库分发的是源代码与来源说明，并不托管统一数据集；部分行情源的条款或访问可用性仍须逐源处理。其“S/B/C”分级来自作者文档，不能代替对每家当前条款的独立法律判断。

推荐定位：**美股／港股数据取用与本地技术指标 Agent Skill**，重点是把政府数据、监管披露和第三方行情来源以代码片段组织起来；已经验证的政府宏观与监管数据可以用，最显眼的期权与报价卖点本轮仍未形成完整实测证据。

结论：政府源和单日 FINRA 路径有真实结果，本地计算可执行；跨源可用性、SEC 与 CBOE 主张仍有明确验证边界。Data 类 14 项全试完后再统一打分与排序。
