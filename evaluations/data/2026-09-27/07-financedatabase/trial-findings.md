## 实际有结果

1. 源码包里的七个本地压缩数据集均可加载：Equities **112,707**、ETFs **36,481**、Funds **57,853**、Indices **91,181**、Currencies **2,556**、Cryptos **3,367**、Moneymarkets **1,367**，合计 **305,512 行符号元数据**。这些是数据行和可能重复的上市形式，不能当作 305,512 家独立公司。README 各类数量与本轮文件一致。
2. README 里的默认 `fd.Equities()` 远端 GitHub Raw 路径正常，约 4.96 秒得到同样的 112,707 行；`use_local_location=True` 可以使用随源码固定的本地快照。
3. 苹果 `AAPL`、茅台 `600519.SS`、腾讯 `0700.HK` 均能精确查到名称、交易所、市场和行业等字段。中国上海交易所筛选返回 1,523 个未标退市的中国公司条目，美国信息技术筛选返回 3,297；ETF 股权类别返回 3,535、Vanguard 名称检索返回 374。这些检索结果只证明元数据可查，未核对全部条目的外部身份。
4. 股票、ETF、基金、指数、外汇、加密和货币市场对象的查询路径均至少返回一种非空样例；对不存在的国家 `Atlantis` 给出明确 `ValueError`。

## 边界与发现

- 官方 README 明确该项目**不提供即时股票数据或更新的基本面**；本轮实际也没有价格、OHLCV、实时流或历史行情。它是全球金融产品符号与分类参考库。
- 符号口径必须转换：本项目使用茅台 `600519.SS`，`600519.SH` 精确查询返回 0；港股腾讯是 `0700.HK`，而其他 API 可能要求 `00700.HK`。模糊查 `00700` 在本轮跨市场返回 5 个条目，不能按第一个结果猜标的。
- Crypto 库虽有 3,367 行，但本轮精确查询 `BTC-USD` 返回 0，而 `ETH-USD` 非空。这表明“覆盖加密资产”不等于常见交易对全有；这只绑定本轮数据快照。
- 默认远端加载指向仓库 `main`，后续数据更新可使同一代码版本取到不同名单；要求可复验时使用固定 commit 下载或本地快照。
- `select()` 默认排除标记为退市的股票：112,707 行原始权益数据缩为 102,303 行；不能把默认结果误认为原始全量。

推荐定位：**覆盖多国股票、ETF、基金、指数、外汇、加密与货币市场的静态符号／行业／分类元数据仓库**。数据对“发现有什么标的、它在哪个市场”很有用；行情研究需要结合别的数据源。

结论：在它宣称的元数据用途上，安装、七类加载、默认远端获取和多市场检索都可用；符号格式与 BTC-USD 空缺是接入时需要注意的边界。Data 类 14 项结束后统一打分排序。
