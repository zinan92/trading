## 限制与目录缺口

- 这个仓库是**静态观察名单 / exposure 本体与参考数据**。它不返回股票价格、历史 K 线、实时行情，也不执行新闻匹配；这些由下游消费者实现。本轮没有测试下游新闻 triage 和行情服务能否正确使用这份名单。
- Trading 目录中的一句简介仍写“6 宏观 / **24** 赛道 / **109** target”，而当前仓库 README 和 YAML 实际是“6 / **26** / **122 次归属**”。这是目录摘要过时，不是 YAML 解析失败。其分类建议在本类别统一发布时一起修正。
- 页面主要是静态说明，缺少搜索/筛选操作入口；相对于看复杂名单，长表阅读成本较高，但源码仓库定位本就是机器可读的权威名单。

推荐定位：**跨市场资产与研究对象的静态 reference registry**，按观察价格的 assets、新闻识别 targets、宏观—赛道—对象关系组织；适合给别的系统提供统一名单，不能与 TickFlow 的行情 API 按实时性直接比较。

结论：在它宣称的参考数据用途上，本轮源码结构、页面对照和远程固定版本取数都通过；Trading 目录摘要需要更新。Data 类分数与排序待 14 项完成后统一给出。
