# tradingview-mcp · Data 类第 3 个首轮试用

- 原仓库：https://github.com/atilaahmettaner/tradingview-mcp （独立开源项目，与 TradingView 官方无隶属关系）。
- 实际源码与目录锁均为 `a1e54b07e5c21b375363607920f297c5adfbeed4`，包版本 `0.9.0`。本机隔离 Python 3.12 环境安装成功，以原生 MCP stdio 启动，无 TradingView 账号、无市场数据 API key。
- [`evidence/probes.json`](evidence/probes.json) 为真实 MCP 调用机器记录；[`evidence/index.html`](evidence/index.html) 与 26 张 [`截图`](screenshots.md) 为 Product Lab 辅助证据界面，**不是上游原生 Web 界面或付费托管 MCP Apps 图表**。

## 实际有结果

1. MCP 初始化通过，`tools/list` 实际列出 **39 个**工具；资源 `exchanges://list` 可读。官方 README 首屏还写 37 个工具，数量口径与当前试用版本不一致，应以本轮实际列表为准。
2. Yahoo 路由返回 AAPL 上一市场时段报价；全球市场快照、比特币市场脉搏得到非空结果。周日测试的美股价格是上次交易时段快照，不能据此验证盘中实时延迟。
3. TradingView screener 路由实际返回美国、A 股、港股各 5 行结果及候选总数；加密涨跌幅筛选、布林带/评级筛选、BTC 技术分析与多周期分析、能源期货、AAPL 期权链及期权异动均有结构化结果。部分超低价币在涨幅榜 `close` 显示 `0.0`，而指标为非零极小值；显示精度对这类标的不足。
4. BTC 单策略三个月日线回测完成 93 根 K，**0 笔成交**；这证明流程能结束，不证明成交统计可靠。另一次一年期滚动样本外回测返回 3 个切分，其中两个测试切分各有 1 笔模拟交易；多策略比较返回排名。回测策略表现未单独审计，更不代表可赚钱。
5. 26 个探针中 **23 项得到结果、3 项明确失败**；本轮成功请求的耗时中位约 1.27 秒，最慢的全球市场快照约 20.3 秒。单次样本不能外推稳定性。

## 限制与问题

- `stock_prices` 双标的报价请求报 TradingView scanner 上游 HTTPS `SSLEOFError`；同一环境下 `stock_screener` 单市场请求正常。因此这是双标的路径在本轮环境的失败，不推断整个 screener 不可用。
- 无 `MARKETAUX_API_TOKEN` 时，财经新闻和市场情绪两条工具返回配置错误。其依赖应在定位中单列。
- 多周期分析运行日志出现一次“无效或空周期，退回日线”的上游警告，但最终仍返回 1W/1D/4h/1h/15m 五栏；各周期是否都使用了正确原始 K 线尚未逐项核对。
- 未验证付费托管服务、MCP Apps 交互图、盘中报价延迟、与交易所源对账、期权链完整性或实时订阅。项目不提交订单。

推荐定位：**多市场研究与技术分析 MCP 服务**，提供股票/加密/期货/期权的公开行情快照、筛选、技术指标和模拟回测；Data 类里偏“数据＋分析工具”，不是纯数据仓库，也不是 TradingView 桌面控制器。

结论：本轮三种股票市场筛选及多条研究流程确实有结果，功能面宽；数据源和功能的可靠度依赖不同上游，少数路由失败或需要可选 key。Data 类全部 14 项完成后再统一打分与排序。
